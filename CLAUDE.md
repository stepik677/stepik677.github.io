# Правила для Claude

- Все изменения коммитить и отправлять прямо в `main` (`git push origin main`), без отдельных веток
  и pull request'ов. Подтверждение владельца не требуется.
- Push в `main` сам публикует сайт и обновление для мобильного приложения
  (`.github/workflows/pages.yml`), поэтому перед push проверять, что `npm run build` проходит.
- Устройство приложения и обновлений — `app/README.md`.
